# Prompt inicial do Gemini — Barzzo

Use este arquivo apenas como ponto de entrada para o Gemini.

1. Carregue `AGENTS.md` e `GEMINI.md`.
2. Se estiver no Gemini CLI, execute `/memory reload` quando necessário e confira o contexto com `/memory show`.
3. Leia `PROMPT_INICIAL_IA.md`.
4. Leia `STATUS.md`.
5. Execute o pedido atual seguindo o contrato universal de `AGENTS.md`.

Não trate este arquivo como fonte exclusiva de regras do projeto.
As regras universais ficam em `AGENTS.md`; `GEMINI.md` contém apenas adaptação específica do Gemini.
